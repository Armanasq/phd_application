# Research protocol
Baseline: 2026-11-11. Status: INCOMPLETE.
Primary current official policy or vacancy > technical repository documentation > firsthand accounts > secondary commentary. Every claim records URL, access date, precision, source class and conflicts. A search hit is not a full audit.
Workflow: discover using synonyms and languages; canonicalize URLs; deduplicate; distinguish funded position, scholarship, program and speculative supervisor lead; verify the original notice, deadlines with timezone, admission versus scholarship and enrollment versus funding dates; test eligibility; record uncertainty and contradictory sources; revalidate before submission.
Confidence classes: VERIFIED_PRIMARY, CORROBORATED, FIRSTHAND_SINGLE, INFERENCE, UNVERIFIED, CONFLICTED.
Repository audit must inspect relevant README and docs, linked sources, actual code/data for tools, commit history, issues, maintenance, privacy, license and transferability. A starred repository is not automatically reliable. Countrywide coverage requires repeat searches with quantitative diminishing-returns logs, not an arbitrary repository count.
Do not commit applicant identity papers, transcripts, scores, passport, residence information, private correspondence, tokens or reference details into this public repository.
