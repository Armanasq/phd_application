# Application operations
States: DISCOVERED -> SCREENED -> VERIFIED -> SHORTLISTED -> PREPARING -> READY -> APPROVED -> SUBMITTED -> INTERVIEW -> DECISION -> OFFER_EVALUATION -> ACCEPTED or CLOSED.
Do not skip states or equate research completion with actual submission. SUBMITTED requires a dated confirmation and application reference in a private ledger.
Application packet: evidence-based CV, research statement describing validated methods and future questions, writing sample, separate institution-tailored research fit, transcripts, language evidence as required and reference coordination. Verify each call's own document and referee format.
Hard gates: authentic fit, official eligibility, funding sufficiency and duration, live deadline including timezone, application channel and permission before contact/submission.
Deadline review: confirm page and changes again just before submitting. No automated emails, applications or offer decisions without explicit authorization.
