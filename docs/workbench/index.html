Safe main-branch workflow

01 · Check existing work

Search the inventory, existing reviews, session manifests, branches and open PRs for the same repository.

02 · Choose a distinct scope

Record session scope in the repository’s established session workflow; a browser checklist is not a shared claim or lock.

03 · Integrate incrementally

Re-read current main and the affected files, preserve concurrent edits, resolve conflicts against both sides, and run relevant validation before a non-force push.

04 · Verify the result

Confirm the main commit, review links and issue acceptance criteria. Keep unresolved work open.
