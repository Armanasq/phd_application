- CV browser-agent extraction needs consent, bounded URL fetch, schema/evidence span validation and homonym resolution.
- Research proposal patterns are *future methods*, not measured experimental results.
- Readme MIT claims can conflict with actual CC BY-NC-ND 4.0 license; reuse must respect the restrictive source LICENSE until resolved.
- The first-class readiness object should record document requirements and verified portal receipts; a draft or template is not an application submission.
