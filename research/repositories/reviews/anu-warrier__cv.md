# Anu-Warrier/CV — preliminary reusable academic-CV template review

**Reviewed:** 2026-11-12; **upstream commit:** [de422fd238d5acd1901072c636702cf4c8c75741](https://github.com/Anu-Warrier/CV/commit/de422fd238d5acd1901072c636702cf4c8c75741).  
**Status:** PRELIMINARY_FOCUSED, source inspection only. **Verdict:** reference document structure and layout, not applicant facts.

The repository contains an extensionless LaTeX source file for an academic CV, a PDF preview and README. The source adapts an earlier CV template, uses a 12pt article layout, tab-aligned dated entries, hanging-indent publication lists and separate section headings. The content includes education, positions, journal and non-journal publications, honors, awards, plus optional teaching and working-paper sections. The style can be adapted to a researcher's dossier after replacing all sample personal details.

The source is a populated person's CV, not a neutral data schema; personal phone, email, address and publications are not reproduced here. The README says the source is permissively reusable, but no standalone LICENSE file exists in the inspected three-file tree. Original-template attribution and derivative reuse terms require independent confirmation.

**Research workflow transfer:** distinguish a comprehensive academic CV from an industry one-page resume. Do not infer an applicant's qualifications or publication metrics from any example. A PhD Atlas private workspace can adopt section coverage as a checklist while retaining the user's original evidence and verified bibliographic records.

**Not tested:** PDF compilation, accessibility, automatic parsing, typography or legal reuse.
