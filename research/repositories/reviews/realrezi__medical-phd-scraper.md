## 1. Purpose, input/output and applicant scope

The [README](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/README.md) advertises a medical/health PhD scholarship scraper using SeleniumBase's UC browser mode to bypass Cloudflare, regex-filter candidates, and save matches to Neon PostgreSQL. This is **niche medical sciences**, not the user's robotics/SLAM/AI fit, and the chosen source is ScholarshipDB, an aggregation surface rather than an official hiring institution. It retrieves candidates, not verified awards. Upstream README example counts such as "2 positions saved" are illustrations, not a live accuracy benchmark.

## 2. Architecture and dataflow

[scraper.py](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/scraper.py) reads SCHOLARSHIP_PAGES (default 10) and NEON_URL from the environment, launches SeleniumBase SB(uc=True,headless=True), visits ScholarshipDB pages for query "Medical Sciences", sleeps five seconds, optionally ten more if Cloudflare strings are detected, then executes a JavaScript selector over h4 a headings. For each item it finds the ancestor li and uses li.innerText as the description. It passes the collected title/description to [filter.py](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/filter.py). Matching rows are passed to [database.py](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/database.py), which creates medical_vacancies if needed and inserts (title,url,description) with UNIQUE(url) ON CONFLICT DO NOTHING. [view_results.py](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/view_results.py) queries by descending serial ID, not by source publication time.

The credentials are environment-sourced; [.env.example](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/.env.example) contains a placeholder, not a real secret. Requirements are SeleniumBase, psycopg2-binary and python-dotenv without version pinning. No retries with backoff, per-host connection budget, terms-aware permission plan, exact source claim capture or institutional cross-verification is present.

## 3. Rule behavior and independently checked edge case

[filter.py](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/filter.py) requires at least one doctoral keyword and one medical-domain term in the concatenated title plus description. It is a coarse classification heuristic, not a doctoral eligibility or applicant specialization assessment. Its doctoral regex is the pattern with a word boundary after "ph.d.": this excludes the otherwise recognizable **"Ph.D."** notation followed by a space, because a period and following whitespace are both non-word characters. A bounded independent Python 3 regex check reproduced that false negative: "PhD candidate" and "Doctorate research" matched; "Ph.D. in medical sciences" and "Ph.D. Candidate" did not. That is a filter-level result only, not a full project test.

The h4 a and ancestor-li assumptions can miss cards or include descriptions from unrelated nested content. The query is fixed to Medical Sciences and paging assumes page=1..N; N is parsed from an arbitrary environment string without a range guard. A published vacancy may require neither keyword in the preview text even when eligible, while a PhD position already closed or ineligible can match.

## 4. Persistence and operational correctness

The database schema contains only ID, title, URL, description. No university ID, timestamp, expiry, source revision hash, verification status, published/corrected deadline, currency, stipend, tuition, institution conditions or independent official-page reference exists. UNIQUE(url) removes duplicate rows only for an identical raw URL: tracking parameters, alternate mirrors, redirects or corrected job terms can create false identities or preserve stale details. ON CONFLICT DO NOTHING prevents updating a changed salary/deadline; there is no refresh or tombstone workflow.

The [database inserter](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/database.py) catches exceptions per row **without rolling back the PostgreSQL transaction**. Once a psycopg2 statement fails, the transaction remains aborted until rollback; later statements will typically fail, and a final commit need not persist intended earlier changes. No explicit connection finally or database retry is present. [view_results.py](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/view_results.py) returns early when the table does not exist, before closing its cursor/connection; operational cleanup is incomplete.

## 5. Safety, privacy, compliance and deployment gaps

SeleniumBase UC mode intentionally tries to work around a Cloudflare challenge; this does not establish permission to crawl the target aggregator. Official APIs or published terms should be preferred, with bounded, identifiable clients. In this implementation network requests are to constructed ScholarshipDB URLs only; it is not a generic user-supplied SSRF endpoint. The code logs scraped listing titles/URLs but not private applicant evidence. The code prints raw database exception details which may reveal operational DB metadata in logs. NEON_URL is required at module import time, making isolated test imports harder and environment secrets mandatory before import.

No production credentials, local .env, live database, institution site or browser run was accessed. The [LICENSE](https://github.com/realrezi/Medical-PhD-Scraper/blob/8b3fa827ff3605a9491b3ff5e8031b52a5609933/LICENSE) is MIT; it grants reuse subject to preservation of the notice, not permission to scrape third-party sites.

## 7. Applicability to PhD Atlas

Keep source-adapter -> deterministic provisional filter -> normalized persistent candidate -> evidence-review stages, but add an authoritative employer page and immutable source snapshot. Record separate academic field, admitted degree stage, funding vs fees, country and applicant class, IANA deadline timezone, validity cycle, retrieved_at/verified_at, and tri-state eligibility. Do not mark a medical match "funded PhD" from ScholarshipDB alone. Modernize DB transaction boundaries with per-row savepoints or batch rollback, canonical URL identity, record corrections and explicit failure receipts; test regex notation variants and live HTML fixtures.
